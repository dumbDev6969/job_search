# System Patterns

## Architecture
- Flask-based MVC architecture
- Blueprint pattern for route organization
- Middleware-based authentication system

## Key Technical Decisions
- Python Flask for backend services
- Bootstrap 5 for frontend components
- AOS (Animate On Scroll) library for UI animations
- Modular route organization by user types

## Component Relationships
- Routes separated by user roles (admin, employer, jobseeker)
- Shared middleware for common authentication checks
- Centralized static assets management

## Critical Paths
- User authentication flow
- Job posting and application process
- Interview scheduling workflow
