# Tech Context

## Technologies Used
- Python 3.x
- Flask web framework
- Bootstrap 5 for frontend
- AOS library for animations
- SQL database (structure shown in import.sql)

## Development Setup
- Install dependencies: `pip install -r requirements.txt`
- Run development server: `python flask_app.py`
- Access via localhost (port configured in flask_app.py)

## Technical Constraints
- Requires Python 3.6+
- Database schema defined in import.sql
- Middleware-based authentication system

## Dependencies
- See requirements.txt for full list
- Key packages: Flask, Flask-SQLAlchemy, etc

## Tool Usage
- Swagger for API documentation
- ngrok for local testing with external services
