1. Project Purpose

This platform is developed as part of a capstone project for academic purposes only. It simulates a real-world job search platform connecting Tech Graduates with Recruiters. The system is not intended for public, commercial, or production use.

2. User Roles

This platform supports the following user roles:

  • Tech Graduates – can register, search jobs, and apply to postings.
  • Recruiters – can register and post jobs.
  • Admins – manage users, job listings, and platform content.

All users in this system are either:

  • Test users created by the development team, or
  • Participants with consent for academic evaluation.
